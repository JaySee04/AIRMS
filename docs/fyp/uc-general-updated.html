Use Case Diagram — General Module

added since the FYP I decomposition
Profiles are view-only plus in-place change-password; identity fields (name, age, gender, sport, programme) are maintained through the Module 4 import or by the administrator, not self-service — there is no self-registration (accounts are provisioned). Per-user permissions are an opt-out model: an administrator revokes individual capabilities from a medical staffer, and the system blocks them server-side while the feature disappears from that staffer's UI.  * The Coach is an experimental fourth role (read-only) outside the locked athlete / medical / administrator model; it can sign in and reset a password but has no profile surface.
