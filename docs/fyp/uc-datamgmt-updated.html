Use Case Diagram — Screening Data Ingestion (Module 3) & Cohort Norms & Governance (Module 4)

added since the FYP I decomposition
The HoloMotion PDF is the only screening import path — the Excel import was retired on 2026-07-12 and archived; the Excel backup export remains (Module 4). Ingestion is a strict pipeline: importing a report includes redacting the athlete's name locally, which in turn includes the vision extraction — so no page image can reach the Vision AI Provider before the name has been obscured. That ordering is the diagram's point, not an incidental layout. Extraction is followed by human verification; nothing is written to the database until the operator commits. Committing an import triggers Module 4's recompute, which includes resolving which athletes are eligible to shape each cohort's reference distribution (manually excluded, currently injured, or below the administrator's minimum scores — eligibility affects the norm calculation only; every athlete is still scored).  * Medical staff reach Manage Cohort Thresholds only when an administrator has granted them the norm-editing capability; the remaining Module 4 use cases are administrator-only.
